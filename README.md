# aimsense

公开的 HTML 页面合集。每个页面都是单文件，下载后可以直接用浏览器打开。

## 页面

### AimSense 灵敏度工坊 · CS2 / Valorant

- 在线地址：https://dandanhuaxianga.github.io/aimsense/aimsense-sensitivity-assistant.html
- 源文件：`aimsense-sensitivity-assistant.html`
- 用途：CS2 / Valorant 灵敏度校准、微调建议与测试流程展示。

### Birthday Wish · 生日祝福页

- 在线地址：https://dandanhuaxianga.github.io/aimsense/birthday-wish.html
- 源文件：`birthday-wish.html`
- 说明：去标识化的生日祝福页公开示例。姓名、日期、经历和信件内容均为占位数据，不包含真实个人信息。
- 交互：刮刮卡、吹蜡烛、礼券、打字机信件和烟花效果。

## 使用

下载对应的 HTML 文件后，直接双击用浏览器打开即可。

Birthday Wish 的麦克风吹蜡烛功能需要 `localhost` 或 HTTPS 环境；其他环境可以使用页面中的“点灭它们”按钮，不影响完整流程。
